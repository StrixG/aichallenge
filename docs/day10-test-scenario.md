# День 10 — Тестовый сценарий (Скользящее окно · Липкие факты · Ветвление)

Цель: один воспроизводимый прогон чата, который **выявляет разницу** между тремя стратегиями
(Сводка исключена). `WINDOW = KEEP_RECENT = 6` сообщений = последние **3** хода. Значит любой факт,
названный за 4+ хода до конца, выпал из скользящего окна — это и есть ловушка сценария.

Как читать: вводи каждую строку **U#** дословно в чат, по порядку. После каждого хода смотри панель
токенов за ход; в конце смотри накопительный счётчик. **Один и тот же** сценарий U1–U8 прогоняется по
разу на каждой стратегии (переключай через чип в верхней панели). Для ветвления — тот же сценарий с
одним форком, см. ниже.

---

## Общий сценарий (все стратегии)

Ранние ходы закладывают два именованных факта (**получатель = сестра**, **бюджет = 5000 ₽**) и
жёсткое ограничение (**аллергия → никакой парфюмерии и косметики**). Финальный ход просит
рекомендацию *без их повторения*. К U7 ходы-закладки уже вне окна из 6 сообщений.

| # | Вводи это (U = ты) | Закладывает / проверяет |
|---|---|---|
| U1 | `Хочу подарить сестре что-нибудь на день рождения, помоги с идеями` | получатель = сестра, повод |
| U2 | `Бюджет не больше 5000 рублей` | бюджет = 5000 ₽ |
| U3 | `Она увлекается горным туризмом и любит кофе` | предпочтения |
| U4 | `Только без парфюмерии и косметики, у неё аллергия` | жёсткое ограничение |
| U5 | `И ещё она левша, учитывай это для всего, что берут в руки` | ограничение |
| U6 | `Можно добавить что-нибудь недорогое для дома` | уточнение (в окне) |
| U7 | `Давай в итоге топ-3 с ценами` | **проверка**: факты не повторены |
| U8 | `Напомни, кому я выбираю подарок и какой у меня бюджет?` | прямое вспоминание U1/U2 |

### Ожидаемое расхождение

- **Скользящее окно**: к U7 в контексте только U5–U7. Топ-3 игнорирует лимит 5000 ₽ и/или правило
  «без косметики»; на U8 не может назвать получателя или бюджет («не уточняли»). Токены промпта
  держатся ~ровно на U1→U7, строки helper-call нет.
- **Липкие факты**: топ-3 остаётся ≤5000 ₽, без парфюмерии/косметики, удобно для левши; на U8 отвечает
  «сестра, 5000 ₽». Каждый ход показывает небольшую стоимость **helper-call** (flash-слияние фактов);
  промпт растёт только на блок фактов.
- **Ветвление**: вся линия U1–U8 в контексте без обрезки; факты соблюдены, на U8 отвечает точно.
  Токены промпта растут с каждым ходом (обрезки нет).

Зачёт = Липкие факты и Ветвление соблюдают всё из {сестра, 5000 ₽, без косметики, левша} на U7/U8, а
Скользящее окно теряет хотя бы бюджет или аллергию.

## Добавка для Ветвления

Тот же сценарий, отличается **только одним ходом**. Цель — проверить, что две ветки ведут независимые
линии и обе переживают перезапуск.

1. На стратегии **Ветвление** пройди U1–U5 как выше.
2. **Форкни** после U5 → ветка **B**. Дальше веди U6 по-разному:
   - ветка **A**, U6 (как в сценарии): `Можно добавить что-нибудь недорогое для дома`
   - ветка **B**, U6b: `А вместо дома добавь что-нибудь в дорогу`
3. В каждой ветке отправь U7 `Давай в итоге топ-3 с ценами`.
   - **A** → в топ-3 есть пункт для дома, нет «в дорогу».
   - **B** → наоборот: есть «в дорогу», нет пункта для дома.
4. **Закрой приложение и перезапусти**, открой чат. Оба чипа веток A и B на месте, и каждая
   воспроизводит свою линию (сохранённое дерево `chat_branches`).

Зачёт = нет перетекания между A и B, и обе ветки появляются после перезапуска.

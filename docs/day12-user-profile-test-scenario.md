# День 12 — Сценарий проверки: заявленный профиль пользователя

Проверяет функционал коммита `feat(settings): add declared user profile for personalization`.

**Что добавлено:** в Настройках появилась секция **Профиль** — *заявленные* предпочтения
пользователя: имя, стиль ответа (`ReplyStyle`), формат ответа (`ReplyFormat`) и свободные
ограничения. Это **не** авто-выученная долговременная память (та *выводится* из диалога),
а то, что пользователь **явно указал**. Профиль:
- подмешивается системным сообщением в **каждый** запрос (`send` и `regenerate`);
- ставится **выше** выученной долговременной памяти — заявленное побеждает выученное;
- пустой профиль не подмешивается вообще (нулевая цена в токенах);
- хранится в SharedPreferences (4 ключа), переживает перезапуск;
- живёт отдельно от памяти: очистка сессии и очистка долговременной памяти его **не трогают**.

**Перед проверкой:**
- Чистый старт: `adb shell pm clear me.obrekht.wishu`.
- Стратегия — любая (профиль ортогонален стратегии).

---

## Карта значений профиля → инструкция модели

| Поле | Значение | Что уходит в системный промпт |
|---|---|---|
| Имя | `Никита` | `Address the user as Никита` |
| Стиль | DEFAULT | *(ничего — не ограничиваем)* |
| Стиль | CONCISE | `keep replies concise and to the point` |
| Стиль | DETAILED | `give thorough, detailed replies with reasoning` |
| Стиль | FORMAL | `use a formal, professional tone` |
| Стиль | PLAYFUL | `use a warm, playful, casual tone` |
| Формат | DEFAULT | *(ничего)* |
| Формат | BULLETS | `present ideas as short bullet-point lists` |
| Формат | PROSE | `write in flowing prose paragraphs, not lists` |
| Ограничения | свободный текст | `Constraints: <текст>` (переводы строк → пробелы) |

DEFAULT/пустые поля **не** попадают в промпт — не сужают модель.

---

## Тест 1 — пустой профиль ничего не подмешивает

1. Чат → панель **Memory layers**, открой счётчик токенов (Token ledger).
2. Профиль в Настройках пуст (после `pm clear`).
3. Отправь: `Подарок другу на день рождения`.

**Ожидание:** ответ обычный. Заявленный профиль в payload **отсутствует** — пустой профиль
(`isEmpty`) не даёт системного сообщения. Зафиксируй число prompt-токенов как базовую линию.

---

## Тест 2 — имя: обращение по имени

1. Настройки → **Профиль** → Имя: `Никита`. Назад в чат.
2. Отправь: `Привет, посоветуй подарок`.

**Ожидание:** ассистент обращается «Никита» — без напоминаний в самом сообщении.
prompt-токенов больше, чем в Тесте 1 (добавилась строка профиля).

---

## Тест 3 — стиль ответа

Поочерёдно меняй **Стиль** в Профиле, повторяя один запрос `Идеи подарка коллеге`:

- **CONCISE** → ответ короткий, по делу.
- **DETAILED** → развёрнуто, с обоснованием.
- **FORMAL** → деловой тон.
- **PLAYFUL** → тёплый, неформальный тон.
- **DEFAULT** → нейтральный (ограничение снято).

**Ожидание:** тон ответа меняется вслед за выбором.

---

## Тест 4 — формат ответа

Запрос `Дай несколько идей`:

- **BULLETS** → маркированный список коротких пунктов.
- **PROSE** → связные абзацы, без списка.
- **DEFAULT** → формат не навязан.

**Ожидание:** форма ответа меняется. (Заметь: парсер `parseWishItems` ловит пункты-списки —
при PROSE кнопок «добавить в список» может не быть, это ожидаемо.)

---

## Тест 5 — свободные ограничения

1. Профиль → Ограничения: `Бюджет всегда до 2000₽, без алкоголя`.
2. Отправь: `Что подарить?`.

**Ожидание:** идеи укладываются в бюджет и без алкоголя — ограничение учтено без повтора в реплике.

---

## Тест 6 — заявленное побеждает выученное (ключевой тест)

1. Профиль → Имя: `Никита`.
2. В чате напиши: `Кстати, меня зовут Борис` (модель может занести «Борис» в долговременную память).
3. Дождись бейджа `обновлено` на **LONG**, проверь панель — там может быть `user_name: Борис`.
4. Отправь: `Как ко мне обращаться?`.

**Ожидание:** ассистент зовёт **Никита**, не Борис. Заявленный профиль подмешан **выше**
выученной памяти → стоящее ниже выученное имя проигрывает.

---

## Тест 7 — частичный профиль (только заданные поля)

1. Профиль: Имя пусто, Стиль `CONCISE`, Формат DEFAULT, Ограничения пусто.
2. Отправь любой запрос.

**Ожидание:** в промпт уходит только строка стиля; ни обращения по имени, ни строки формата,
ни ограничений. DEFAULT/пустые поля молчат.

---

## Тест 8 — персистентность (переживает перезапуск)

1. Задай профиль (имя + стиль + формат + ограничения).
2. Полностью закрой и заново открой приложение.
3. Настройки → **Профиль**.

**Ожидание:** все 4 поля на месте (читаются из SharedPreferences). Новый чат сразу
учитывает профиль.

---

## Тест 9 — профиль ≠ память (очистка не трогает профиль)

1. Профиль задан (имя `Никита`).
2. Чат → **метла** (Clear session) → SHORT/WORK очистились.
3. Настройки → секция **Память** → **Очистить долговременную память** → Удалить.
4. Вернись в Настройки → **Профиль**.

**Ожидание:** профиль **цел** — это настройки, а не память. Ни очистка сессии, ни очистка
долговременной памяти его не стирают. Сбрасывается только вручную, редактированием полей.
